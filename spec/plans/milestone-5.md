## 3. בדיקות מקדימות שלי (לפני כל פעולה מול Vercel)

1. `npm run lint` ו-`npm run build` עוברים בלי שגיאות.

3. וידוא ש-`.env` אינו ב-Repository (`git ls-files`), ושהמפתח אינו מופיע בקובצי ה-Build שנשלחים לדפדפן (`.next/static`).

## 4. פעולות שלך מול Vercel ו-OpenAI — בהדרכה צעד אחר צעד

> אני מדריך אותך בשפה פשוטה, מסך אחר מסך. אני לא מבקש ממך להדביק מפתחות בשיחה, ולא נוגע בחשבונות שלך.

### 4.1 Spend Limit ב-OpenAI
בכל אחד משני ה-Projects (פיתוח ו-Production): כניסה ל-platform.openai.com ← בחירת ה-Project ← Settings ← Limits, ווידוא שמוגדר Hard Limit של 10$ בחודש.

### 4.2 חיבור Vercel
1. יצירת חשבון Vercel (תוכנית Hobby), בהתחברות דרך GitHub.
2. Add New ← Project ← בחירת ה-Repository ‏`hahaha` ← Import. Vercel מזהה Next.js לבד; לא משנים הגדרות Build.
3. **לפני** הלחיצה על Deploy — הגדרת משתני הסביבה (סעיף 4.3). אם הפריסה הראשונה כבר רצה בלי משתנים, היא תעבוד אבל בדיחות ייכשלו; אחרי ההגדרה עושים Redeploy.

### 4.3 משתני סביבה ב-Vercel (Settings ← Environment Variables)

| שם | ערך | היקף | Sensitive |
|---|---|---|---|
| `OPENAI_API_KEY` | מפתח ה-Project **Production** ב-OpenAI | Production בלבד | כן |
| `OPENAI_API_KEY` | מפתח ה-Project **פיתוח** ב-OpenAI | Preview בלבד | כן |
| `OPENAI_MODEL` | `gpt-5` | Production + Preview | לא |

### 4.4 פריסת Production
- הפריסה הראשונה נוצרת מה-Import (או מ-Redeploy אחרי הגדרת המשתנים). הכתובת: `https://<שם-הפרויקט>.vercel.app`.
- לאחר מכן, `README.md` (וסימוני ההתקדמות) ייכנסו ל-`main` רק כשתבקשי "דחוף שינויים לגיטהאב" — וזה ייצור פריסת Production נוספת, אוטומטית.

### 4.5 בדיקת Preview (דורש אישור שלך ל-push)
כדי לוודא ש-Preview נוצר אוטומטית ומשתמש במפתח הפיתוח: אדחוף ענף קצר בשם `preview-check` (בלי שינוי קוד מהותי), Vercel ייצור כתובת Preview, ונבקש בה בדיחה אחת. **אבקש את אישורך לפני ה-push**, ואת אישורך למחוק את הענף אחר כך.
- הערה: כתובות Preview ב-Vercel מוגנות כברירת מחדל — נפתחות רק כשמחוברים לחשבון ה-Vercel שלך. זה תקין ורצוי.

### 4.6 וידוא איזה מפתח משמש איזו סביבה
אחרי בקשת בדיחה אחת ב-Production ואחת ב-Preview: בלוח הבקרה של OpenAI ← Usage, מסננים לפי Project. בקשת ה-Production צריכה להופיע רק ב-Project ה-Production, ובקשת ה-Preview רק ב-Project הפיתוח. (העדכון בלוח עשוי להתעכב כמה דקות.)

- בלוגים של Vercel (Logs) — אין תוכן נושא או בדיחה, רק סוג שגיאה וקוד סטטוס. את הלוגים תפתחי את, ואני אגיד לך מה לחפש.
- רוחב התוכן במחשב מוגבל ל-480px וממורכז.

## 6. תיעוד החלפת המודל — סעיף ב-`README.md`

תוכן הסעיף (בעברית):
- **המועד:** ‏`gpt-5` מוסר מה-API של OpenAI ב-**11 בדצמבר 2026**. מומלץ לבצע את ההחלפה עד **1 בדצמבר 2026**, כדי שיישאר זמן לתקן אם משהו לא עובד. (היום: 21 באוקטובר 2026 — נשארו כ-7 שבועות.)
- **המודל המומלץ להחלפה:** ‏`gpt-5.6-sol` (לפי ARCHITECTURE 1.3). לפני ההחלפה כדאי לוודא שוב בעמוד ה-Deprecations של OpenAI.
- **התהליך:**
  1. מקומית: לשנות את `OPENAI_MODEL` ב-`.env`, להריץ `npm run dev`, ולבדוק כמה בדיחות (עברית, אנגלית, ריק, סירוב).
  2. ב-Vercel: לשנות את `OPENAI_MODEL` בהיקף **Preview** בלבד, ולבצע Redeploy לפריסת Preview. לבדוק שוב בכתובת ה-Preview.
  3. רק אחרי שהכול עובד: לשנות את `OPENAI_MODEL` בהיקף **Production**, ולבצע Redeploy ל-Production. לבדוק בטלפון בדיחה אחת.
- **סיכון ידוע:** הקוד שולח את רמת ה-Reasoning ‏`minimal` (ב-`lib/joke-service.ts`). אם המודל החדש לא תומך בה, הבקשה תיכשל כבר בשלב 1 (בהרצה המקומית) — ואז נדרש שינוי קוד קטן לפני שממשיכים. זו הסיבה שבודקים קודם מקומית וב-Preview.
- **תזכורת:** את מוסיפה בעצמך תזכורת ביומן ל-1 בדצמבר 2026 (אני לא ניגש ליומן שלך).
